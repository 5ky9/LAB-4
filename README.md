## Лабораторная 4 — вёрстка

### Box model карточки (часть 1)
Измерено в DevTools (viewport 1280 px):
- content: 563 px, padding: 16px, border: 1px, margin: 0
- итоговая ширина карточки на экране: 597 px (563 + 2·16 + 2·1)
- без `box-sizing: border-box` при том же `width` карточка стала бы шире на padding + border (34 px);
  с `border-box` заданная ширина включает padding и border, поэтому карточки ровно
  делят колонку сетки и не вылезают за неё.
- В дереве элементов до рефакторинга сплошные `<div>`: по тегам нельзя понять, где шапка,
  где каталог, где подвал.

### repeat(4, 1fr) на узком экране (часть 4)
Колонок всегда 4, поэтому на ~500 px карточки сжимаются в узкие полосы (около 100 px),
названия переносятся по слогам, кнопки и картинки теснятся, вёрстка разваливается.

### auto-fit vs auto-fill (часть 4)
`auto-fit` схлопывает пустые колонки и растягивает оставшиеся карточки на всю ширину;
`auto-fill` сохраняет пустые колонки, и 1-2 найденные карточки остаются узкими.
Выбран `auto-fit`.

### Адаптивность (часть 5)

| Ширина | Колонок в каталоге | Где «Доставка» | Шапка |
|--------|--------------------|----------------|-------|
| 375    | 1                  | под каталогом  | столбик |
| 768    | 3                  | под каталогом  | ряд |
| 1280   | 3 (каталог = 3fr из 4fr) | справа   | ряд |

«Товар недели» на 375 px занимает 1 колонку (343 px), на 768 px и шире - 2 колонки.

### Ответы на вопросы для защиты
- `<section>` - тематический раздел страницы, `<article>` - самостоятельный, переиспользуемый
  блок; карточка товара имеет смысл сама по себе, поэтому это `<article>`.
- `<main>` - основное содержимое страницы, оно одно; разделов `<section>` может быть много.
- `border-box` включает padding и border в `width`; без него итоговая ширина больше заданной.
- Шапка - одномерный ряд (Flexbox); каталог - двумерная сетка строк и столбцов (Grid).
- `repeat(auto-fit, minmax(220px, 1fr))`: столько колонок, сколько влезает при ширине не меньше
  220 px, остаток делится поровну.
- Mobile-first: базовые стили для телефона, для больших экранов `min-width`; на телефон
  не грузятся лишние переопределения.
- `<label htmlFor>` связывает подпись с полем (клик, скринридер); `type="email"` даёт проверку
  наличия «@» и нужную клавиатуру на телефоне.
